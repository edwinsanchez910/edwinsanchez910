# # Hola, soy Edwin Sánchez 👋 

## ## QA Automation Engineer | Aseguramiento de Calidad Orientado al Negocio
Especialista en QA Engineering con sólida base técnica enfocado en la creación de estrategias de pruebas que garantizan la estabilidad del software, la detección temprana de defectos y la optimización de procesos de entrega. Experto en diseñar e implementar frameworks de automatización robustos y escalables que protegen la continuidad del negocio y mejoran la experiencia del usuario final.

🚀 **Mi enfoque:** Tras un proceso de autotransformación de alta disciplina, he consolidado un perfil técnico versátil capaz de abordar la calidad desde múltiples frentes: desde la automatización avanzada de flujos críticos de negocio en entornos Web, Mobile y APIs, hasta el análisis profundo de datos y la gestión de infraestructura.

---

## 🛠️ Tecnologías y Herramientas

### 🤖 Automatización de Pruebas (Web, Móvil y APIs)
*   **Java & Serenity BDD:** Implementación de pruebas automatizadas escalables bajo el patrón de diseño **Screenplay**, integrando **Cucumber y JUnit** para asegurar la legibilidad del negocio.
*   **Python & Selenium:** Desarrollo de scripts eficientes con **PyTest** y **PyCharm** para la validación automática de flujos de usuario interconectados.
*   **Mobile Testing & API Testing:** Pruebas integrales en dispositivos reales/emuladores mediante **Android Studio** (logs ADB) y validación automatizada/manual de endpoints con **Postman**.

### 📊 Análisis de Datos & Servidores
*   **Bases de Datos:** Construcción de consultas complejas en **SQL (PostgreSQL)** para la extracción de métricas de calidad, lógica condicional y validación de la integridad de los datos.
*   **Infraestructura:** Gestión segura de servidores vía **SSH** y automatización de tareas del entorno operativo en **Bash/Linux**.

### 🎯 Gestión de Calidad y Estrategia
*   **Gestión de Defectos:** Control, documentación y seguimiento de bugs utilizando **Jira, TestRail** y metodologías ágiles (**Scrum**).
*   **Diseño de Pruebas Basado en Negocio:** Modelado de diagramas de flujo para identificar rutas críticas (*happy paths*), mapas mentales para asegurar una cobertura de pruebas al 100% y elaboración de matrices de prueba preventivas.
